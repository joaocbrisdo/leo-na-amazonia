# Léo na Amazônia

Jogo educativo de plataforma em português. Guie Léo pela floresta, colete letras para formar nomes de animais amazônicos e responda aos desafios de verdadeiro ou falso sobre cada espécie.

**[Baixar o jogo para Windows (32 bits, 38 MB)](https://github.com/joaocbrisdo/leo-na-amazonia/releases/download/entrega-academica/Leo_Amazonia_32.zip)** · **[Baixar o projeto Godot completo](https://github.com/joaocbrisdo/leo-na-amazonia/releases/download/entrega-academica/Projeto_Godot.zip)**

## Como jogar no Windows

1. Baixe o jogo pelo primeiro link acima.
2. Clique com o botão direito em `Leo_Amazonia_32.zip` e escolha **Extrair tudo**.
3. Na pasta extraída, abra `LeoNaAmazonia.exe`.

| Ação | Controle |
|---|---|
| Andar | A e D ou setas esquerda e direita |
| Pular | Espaço, W ou seta para cima |
| Escolher letras e respostas | Clique com o mouse |
| Desfazer a última letra | Backspace |

## Avaliar o projeto

Extraia `Projeto_Godot.zip`. No gerenciador da Godot 4.7, escolha **Importar**, selecione `leo-na-amazonia/project.godot` e pressione **F5** após a importação. Em `scripts/` está a lógica do jogo. Em `docs/GDD.md` estão as regras, o público e a progressão das fases. O arquivo `MELHORIAS.md` descreve as revisões dos scripts.

Os dois pacotes foram fornecidos separadamente para esta entrega acadêmica. O executável publicado é o original recebido para avaliação.
